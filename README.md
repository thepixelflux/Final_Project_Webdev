This project is my personal rendition of the official TDA Website, crafted to reflect the excitement, structure, and opportunities offered by the bootcamp.
Throughout this project, I explored the art of crafting responsive web pages, balancing design with functionality. I discovered the value of semantic HTML for creating well-structured, accessible content and used CSS to enhance user experience and maintain a cohesive brand identity. Finally, I dipped my toes into JavaScript to add a touch of interactivity—bringing the site to life as a vibrant, user-centric experience built from the ground up.
As someone exploring web development for the very first time, this project represents my growth throughout the bootcamp and showcases my understanding of front-end technologies.
